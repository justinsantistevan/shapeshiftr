# Lovable first prompt for fitness tracker: ShapeShiftr

let's build a website (that is mobile responsive) that is a dashboard of my physical fitness progress.  Here are things it should do, hopefully all in a single page with different components:
- user authentication: i will be the only user, but i want access to be behind a username and pw
- Title of site/app should be: ShapeShiftr
- create a cool logo for ShapeShiftr, modern, clean
- an inspirational quotation (an actual quote, attributed to its author) at the top that changes each time the app/page is accessed: topic should be about either achieving goals, doing hard things, consistency in good habits, pushing through plateaus, steady progress through small actions done consistently, taking care of our fitness, etc.  There is also a "refresh" icon next to it (keep it subtle) that will change the quote.
- display bar chart with various data sets that can be selected to display (up to 2 metrics at the same time: one labeled on left axis, a second on right axis); metrics to display: weight (lbs, one decimal point), body fat % (one decimal point), skin fold measurement (stomach, in mm) average calories consumed in prior week, avg. daily exercise minutes in prior week
- a pop up screen/modal that lets me enter data for each of the above metrics: choose a week (each week should start on a Sunday, starting with July 27, 2025), then enter values for each of the above metrics; also can select prior weeks to enter any missing data or update any values
- display my goal for each of the metrics; the goal will also display on the bar chart (as a line) for whatever metrics are currently being displayed
- a method for updating the goal for each metric
- a carousel of photos (I will upload 2 photos for each week, one from front, one from side) that I can scroll through to show how my body physically changes from week to week; also want the ability to "pin" one week's set of photos and then scroll through other weeks so that I can compare (like a before and after comparison)
- style/vibe should draw inspiration from other top fitness brands: Peloton, Strength+, Apple Fitness, Nike; have a light/dark mode selector somewhere near top of page
- list of fitness affirmations at the bottom of the page, which are:
    - I can do hard things.
    - I am disciplined.
    - I have pain-free flexibility in my shoulder.
    - My knee gets stronger every day.
    - I enjoy working hard during workouts.
    - I choose long term goals over short term gratification.
    - If we overestimate what we can accomplish in a month, we underestimate what we can achieve in 6 months.
